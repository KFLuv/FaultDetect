# FaultDetect 安全边界

适用版本：v1.2.0

## 产品定位

当前版本是本机单用户排障工具，不是局域网共享服务。

## 网络边界

- Spring Boot 只监听 `127.0.0.1`。
- API 过滤器再次检查来源地址，只接受回环地址。
- 移除任意来源 CORS。
- 不自动跟随重定向，3xx 作为观测结果保留。

## 目标授权

每次检测请求必须带：

```json
{
  "authorized_target": true
}
```

前端要求用户主动勾选“已获得目标系统诊断授权”，否则不会调用检测接口。

## 请求安全

- 只发送 GET / HEAD。
- 自定义请求头名称只允许字母、数字和连字符。
- 拒绝包含换行符的请求头值。
- 不执行登录、提交、删除、发送等写操作。

注意：某些系统可能错误地把 GET 设计成有副作用的操作，因此 HTTP 方法本身不能替代用户授权。

## 数据边界

- 自定义认证头不写入历史。
- 历史与导出 URL 会遮蔽 token、key、password、session、auth 等查询参数。
- 默认保留任务 180 天，可用 `FAULT_DETECT_RETENTION_DAYS` 覆盖。
- 支持单条删除和清空全部历史。

## LLM 边界

- LLM 默认关闭。
- 只有用户勾选增强分析且后端已配置时才调用。
- 调用失败自动降级，不影响规则结论。
- 真实 Key 只写入 `%USERPROFILE%\.faultdetect\application.properties`，不进入仓库。
- 配置查询只返回打码 Key，不返回明文。
- 连接测试只返回状态、耗时和错误信息，不返回请求头或密钥。

## 未支持

- 局域网多人共享。
- 云端多租户。
- 统一身份认证和角色权限。

在这些能力完成前，不开放远程访问。
