# 原型说明

> **本目录的图是低保真线框图**，用途是说明**交互结构与信息层级**，不是最终视觉稿。

## 为什么是低保真

我没有 Axure 授权，所以用代码绘制等价线框图。

**这不影响它要证明的东西** —— 对产品岗而言，原型要证明的是：

| 原型要证明的 | 这几张图里怎么看 |
|---|---|
| **信息层级设计** | 结果页把「观测层 / 归因层 / 结论层」做成三个**视觉上明显不同的区块** |
| **用户认知路径** | 每个区块右上角标注「我实测到的 / 我推的 / 我的建议」 |
| **风险提示设计** | 低置信假设用橙色标注「证据强度弱，请注意」 |
| **边界声明** | 结论层底部固定一行「**本次我判不了的**」 |
| **安全设计可视化** | 首页把「只读白名单 / 运行时拒绝写操作」直接展示在界面上 |

## 这四张图对应的产品决策

| 界面元素 | 背后是哪条决策 |
|---|---|
| **三层分区 + 不同视觉层级** | 决策 3：**不要把推断当事实展示** |
| 每条假设的三行（依据/反证/验证） | 决策 4：**结论要可被推翻** |
| 「本次我判不了的」固定区块 | 决策 3 + 已知边界专章 |
| 弱证据橙色警示 + 低置信度 | **不给单一总分**，改为给计数与清单 |
| 首页「只读白名单 / 运行时拒绝」 | 决策 6：**先定义红线，再定义功能** |
| 自检页「对外应报 7/8」 | **口径诚实**：放宽标准算出来的 100% 不能当证据 |
