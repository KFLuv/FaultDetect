# FaultDetect 模拟现场任务验收

日期：2026-11-05
版本：FaultDetect v1.1.0
验证类型：本地模拟现场任务 + 本人验收

说明：本记录验证产品链路和失败状态，不是独立真实用户研究。

## 任务目标

模拟实施人员收到四类现场反馈：

1. 页面返回 404；
2. 页面返回 500；
3. 页面显示空表格；
4. 提交后提示数据重复。

要求系统完成：

```text
输入 URL 与症状
→ 服务与 HTTP 观测
→ 差分隔离
→ 归因假设
→ 报告文本
→ 历史记录
→ 对无效输入给出明确失败
```

## 测试目标

本地只读 mock 服务：

`http://127.0.0.1:18080`

| 路径 | 构造结果 |
| --- | --- |
| `/missing` | 404 |
| `/error` | 500 + NullPointerException |
| `/empty` | 200 + 空 data |
| `/duplicate` | 417 + TooManyResultsException |

## 结果

| 场景 | 报告号 | 状态码 | 步骤 | 差分实验 | 根因层 | 最高假设 |
| --- | --- | --- | ---: | ---: | --- | --- |
| 404 | `RPT_20261105233652011001` | 404 | 10 | 7 | 前端 | 前端路径错误 |
| 500 | `RPT_20261105233652071002` | 500 | 10 | 7 | 后端 | 空指针异常 |
| 空数据 | `RPT_20261105233652118003` | 200 | 10 | 7 | 数据库 | 数据库无数据 |
| 数据重复 | `RPT_20261105233652147004` | 417 | 10 | 7 | 数据库 | 业务异常被映射为 417（单行查询返回多行） |

## 报告与跟进

- 四条结果都包含 `report_id`、URL、状态码、检测步骤、差分实验、证据链、结论、解决建议和汇报模板。
- 报告号包含毫秒和序号，连续检测不会重复。
- `/api/history` 返回 4 条历史，可用于后续跟进。
- 前端报告区存在“复制汇报文本”按钮，并保留 Clipboard API 失败时的选区复制兜底。
- 本次自动化验证确认报告文本字段完整；浏览器剪贴板动作仍需人工点击确认。

## 失败路径

输入 `http://`：

- 接口返回 400；
- 服务继续运行；
- 不生成伪造报告；
- 用户可以修正 URL 后重试。

## 结论

FaultDetect 已具备一条可运行的产品闭环：

> URL 输入 → 观测 → 差分 → 归因 → 报告 → 历史跟进 → 失败重试

## 未覆盖

- 没有第二个独立用户参与。
- 没有连接真实企业内网系统和真实日志平台。
- 没有验证不同 Windows 版本、不同屏幕尺寸和长期运行。
- 没有把本地 mock 结果外推为所有真实系统的诊断准确率。
