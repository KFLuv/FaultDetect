# FaultDetect v1.2.0 产品化验证

日期：2026-11-06

## 已完成

| 能力 | 证据 |
| --- | --- |
| 本机安全模式 | 仅监听 `127.0.0.1`，健康接口返回 `security_mode=local-only` |
| 目标授权 | 未授权检测返回 HTTP 400 |
| 诊断任务状态 | 新建、排查中、待确认、已修复、已关闭 |
| 跟进字段 | 负责人、备注、关闭原因 |
| 报告生命周期 | JSON 导出、Markdown 导出、单条删除、清空全部 |
| URL 脱敏 | 历史中 `token=***` |
| 旧库迁移 | 旧历史恢复，默认状态补为 `new` |
| 重启持久化 | 新任务状态与负责人在重启后保留 |
| 浏览器自动化 | 六个导航、授权检测、复制、跟进、重新检测、主题、移动端 |
| 单文件交付 | v1.2.0，内置 JRE，后端由 `javaw` 启动 |
| 本机 LLM 配置 | Key 打码、保存立即生效、连接测试通过 |
| LLM 开关 | 关闭不请求；开启后 `status=ok`，规则结论保持 |
| 未知场景模式 | 低置信不强行匹配，生成采集清单、七层状态、下一项实验和交接包 |
| 场景学习 | 最终根因自动加入自定义场景，生成待审核规则候选，同类问题再次命中 |

## 当前边界

- 没有第二个独立真实用户。
- 不开放局域网多人访问。
- 真实日志、数据库和业务规则仍需现场授权复核。
- 当前为单机单用户安全模型。
