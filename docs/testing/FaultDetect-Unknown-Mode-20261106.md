# FaultDetect 未知场景模式验证

日期：2026-11-06
版本：FaultDetect v1.2.0

## 目标

验证知识库没有高置信场景时，系统不会强行套用候选，而是进入可执行的现场排障流程。

## 输入

- 状态码：599
- 响应：`VendorWidgetUnavailableException: palette cache mismatch`
- LLM：关闭

## 输出

- `unknown_mode.active=true`
- `match_suppressed=true`
- 现场采集清单：9 项
- 分层判断：7 层
  - 端口
  - 服务
  - HTTP
  - 鉴权
  - 业务
  - 数据
  - 前端
- 已排除：端口、服务
- 当前怀疑：业务
- 未确认：鉴权、数据、前端
- 下一项只读实验：3 项
- 研发交接包：已生成

## 自动学习

提交最终根因后：

- 自定义场景数从 132 增加到 133
- 新场景 ID：`SCN_133`
- 任务状态更新为 `fixed`
- 生成 `rule_candidates.json`
- 规则候选状态为 `pending`

再次执行同一 599 故障：

- 进入高置信场景，不再进入未知模式
- 命中场景：`SCN_133`
- 实证置信度：0.93

## 边界

- 通用规则候选必须人工审核，不直接修改规则代码。
- 自动沉淀的是具体故障场景，不代表所有相似现象都已覆盖。
