## 当前边界

- 完整诊断范围仍是 Web HTTP / HTTPS；
- POST 等写请求只做失败快照，不自动重放；
- 不支持原浏览器监听、手机 App、原生客户端、WebSocket、SSE 和系统级全流量；
- 不替代服务端日志、APM、数据库审计和抓包；
- 不承诺仅凭一次 HTTP 响应定位所有系统的最终根因。
