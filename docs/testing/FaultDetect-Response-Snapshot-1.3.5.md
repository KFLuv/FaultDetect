# FaultDetect v1.3.5 不可重放请求快照验证

日期：2026-11-07
验收对象：`FaultDetect-1.3.5-portable.exe`

## 目标

让 POST、审批、提交等不能安全重放的请求，也能保留原始失败证据并完成第一层归因。

## 实现

- 内嵌 webview 通过 Chromium 调试协议读取原始响应。
- 保存 HTTP 状态、响应头、耗时和脱敏响应体。
- 从响应头和响应 JSON 提取 Trace ID。
- 响应体最多保存 12,000 字符。
- 常见 Token、Password、Secret、API Key 和 URL 凭证在展示前脱敏。
- 完成采集时等待在途响应体归档，再关闭页面。

## 验证结果

- GET 500 请求：原始响应快照成功。
- POST 500 请求：原始响应快照成功。
- POST 请求：仍不可自动重放。
- 响应体：包含 `DemoServiceException`。
- Trace ID：成功从 `X-Request-Id` 读取。
- 剪贴板：包含操作、状态、问题层、初步原因、下一步和 Trace ID。
- 页面上可打开“失败快照”查看状态、问题层、Trace ID、耗时和响应体。

## 已知边界

- 快照不能替代服务端日志、APM、数据库和完整调用链。
- 浏览器响应体并非所有请求都允许调试协议读取。
- 二进制响应按文本方式截断，只适合辅助定位，不用于文件分析。
- 脱敏采用常见字段规则，不代表完整的组织数据分类分级。
