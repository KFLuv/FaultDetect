# FaultDetect v1.3.1 后端断线恢复验证

日期：2026-11-06
验收对象：`FaultDetect-1.3.1-portable.exe`

## 目标

复现点击“开始检测”时出现的 `fail to fetch`，验证桌面端能识别本地后端断开、自动重启并重试原检测请求。

## 测试步骤

1. 启动打包后的 Electron 桌面版，确认 `/api/health` 返回 `1.3.1`。
2. 打开故障检测页，填写本地模拟目标和症状。
3. 强制终止当前内置 `javaw` 后端，模拟页面与本地服务断连。
4. 点击“开始检测”。
5. 检查是否出现浏览器原生 `fail to fetch`，并等待诊断报告。

## 结果

- 被终止的后端 PID：`38012`。
- 前端未弹出 `fail to fetch`。
- 桌面端自动启动新的后端进程。
- 原始检测请求被重试并成功返回 500 报告。
- 恢复后的 `/api/health.version` 为 `1.3.1`。

## 结论

本次验证覆盖了“页面已经打开、本地后端突然退出、用户继续点击检测”的失败路径。桌面端不再把底层网络错误直接暴露给业务用户。
